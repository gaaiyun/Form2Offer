让 Agent 主动读取浏览器表单

        
开启后，Claude Code、Codex 等 MCP Agent 可以用 form2offer_read_form 直接读取你当前打开的网申页（字段、选项、已填内容；证件号、密码、验证码会打码），并提交填写方案。方案仍要你在弹出的审阅页确认后才写入网页。需要授予扩展访问网站的权限。
