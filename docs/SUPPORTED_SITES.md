# 平台与控件支持范围

招聘网站会持续更新页面。下表描述代码中的当前规则，不代表永久兼容或平台官方授权。

## 国内 ATS 启发式规则

- 北森与 `*.zhiye.com` 租户页面
- Moka 招聘页面
- 飞书招聘页面
- HotJob / Phoenix 类组件
- 智联、猎聘、牛客常见字段和页面结构

## 已用真实结构回归的平台

- **北森 Phoenix（`*.zhiye.com` 新版门户）**：`tests/fixtures/beisen-phoenix.html` 按真实租户的页面结构复刻，`scripts/qa-beisen-fixture.js` 在浏览器里跑完整填写。覆盖月份面板日期、按天日历、“至今”复选框、需点内层的单选、带搜索的下拉、逐级地区选择器（籍贯单选、期望城市多选）、经历记录里的“添加”按钮。
- 各平台的登录方式、简历解析是否会覆盖已填内容、怎样算真正提交，见 `src/platform-knowledge.js`，填写面板里点“本站注意事项”也能看到。

## 通用页面

Form2Offer 会扫描当前页的文本框、文本域、原生下拉、日期、单选、多选，以及部分 React/Vue 自定义控件。BOSS 直聘、前程无忧和企业自建招聘页可以使用通用规则，但当前没有“全站稳定兼容”承诺。

## 常见限制

- 多步骤页面切换后需要再次点击“开始填写”。
- 北森以外平台的级联省市区、虚拟滚动下拉、富文本编辑器、跨域 iframe、关闭的 Shadow DOM 可能需要手动处理。
- 附件上传、验证码、短信校验、测评和考试页面不会自动操作。
- 声明、亲属回避、背景调查和最终提交默认由用户确认。
- 赛码等考试/测评场景不属于本项目目标范围。

提交新平台适配时，请使用匿名化 fixture，并遵守 `CONTRIBUTING.md` 的隐私要求。
