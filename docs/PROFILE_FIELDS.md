# 网申资料字段范围

Form2Offer 设置页按国内校招常见结构维护资料。没有内容的字段可以留空，空值不会写入网页。

| 模块 | 主要字段 |
| --- | --- |
| 基本信息 | 姓名、拼音、联系方式、证件、政治面貌、户籍、生源地、地址、应届身份、毕业年份、健康、紧急联系人 |
| 求职意向 | 应聘单位/部门、第一和第二志愿、地点、薪资、到岗时间、异地及岗位调剂 |
| 教育经历 | 学校、专业、院系、学历学位、GPA 分数/满分、平均成绩、排名及总人数、证书编号、辅导员 |
| 实习/工作/绩效 | 单位、部门、行业、职位、内容、成果、证明人、离职原因、年度绩效 |
| 项目/校园 | 项目名称、角色、职责、成果、链接、参与人数、学生工作和社会实践 |
| 奖项/语言/技能/证书 | 时间、名称、等级、成绩、证书编号、授予单位和有效期 |
| 家庭情况 | 姓名、关系、性别、出生日期、学历、职业、单位、职位、政治面貌、退休及金融从业情况 |
| 培训/论文/专利 | 培训课程与证书、论文刊物和作者顺序、专利编号与成果 |
| 自我描述/网申问答 | 自我评价、优缺点、职业规划、申请公司和岗位原因、挑战经历 |
| 有关声明 | 亲属回避、疾病、不良或失信记录、处分、刑事处罚、竞业、利益冲突、兼职持股、境外居留和背调授权 |

证件、家庭、健康、政治面貌等字段属于敏感资料；声明和合规问答可能产生法律或录用后果。两类字段默认只标记，不自动填写。
